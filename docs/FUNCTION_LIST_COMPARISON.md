# Jami function list comparison: iOS vs HarmonyOS

- **Source:** Jami for iOS 4.20, 526 functions.
- **Target:** Jami for HarmonyOS (this repository, `master`).
- The iOS function list was taken from the final-round QA workbook: each user interface element its
  1588 test cases name is one function, and cases that name no element were matched to the
  function they test or given a row of their own.
- Each function was run on an iPhone with Jami 4.20 and then on this port on a Huawei phone with
  HarmonyOS NEXT. Functions whose first run failed on HarmonyOS were fixed and run again.
- ✅ = the app has the function, ❌ = it does not, or it could not be shown to work.
- The levels follow the Function List format of `function-list-pipeline`. Level 1 Module is an area of
  the app; Secondary Module is a screen, sheet or menu in it; Three-level module and Level 4 Module are
  the elements tapped from it, one level per tap. A row ends at its own level, so the deeper columns stay
  empty. Anything deeper than Level 4 is joined into Level 4 Module with `>`.
- As in the Function List workbook, a module, screen or element is one merged cell over all the rows of
  its group. A markdown table cannot merge cells, so the two tables below are written in HTML.
- The functional description comes from the expected results of the test cases. The port has no
  function list of its own, so there are no HarmonyOS-only rows (– in the summary).
- 484 rows: 483 in both, 1 iOS only.
- 42 iOS functions were left out of the comparison, because QA set aside every test case that
  covers them; they are listed after the table.
- The same tables are in the workbook [FUNCTION_LIST_COMPARISON.xlsx](FUNCTION_LIST_COMPARISON.xlsx),
  with each group as merged cells.
